What this can and cannot answer

TikTok has no tracking anywhere in our stack. We checked every Braze custom attribute name and value across 189 recent profiles, every campaign, canvas and segment name, all Braze tags, all 43 Everflow affiliates, and every Everflow sub-id. Zero references. Traffic source is stored only as a numeric Everflow affiliate ID, so a TikTok visitor is currently indistinguishable from an untracked direct visitor. Nothing here confirms or rules out TikTok's contribution.

The headline

September is running softer than August on both volume and efficiency. Quiz abandons are averaging 301 a day against August's 330, down -8.9%. Tracked clicks are essentially flat at 4,134 a day versus 4,199, a change of -1.5%.

Because clicks held steady while abandons fell, the efficiency measure moved down too: 72.8 abandons per 1,000 tracked clicks in September against 78.7 in August, a drop of -7%.

This matters for the attribution question. The large intake growth happened between July and August, when abandons rose from roughly 200 a day to a peak above 400. September has given some of that back. If a new traffic source came online recently and is driving incremental quiz intake, September is not yet showing it in either the volume or the efficiency numbers.

What would settle it

Create a TikTok affiliate in Everflow and route all TikTok ad traffic through its tracking link. Every visitor then carries an affiliate ID that lands on the Braze profile as affid, exactly as Meta, Google, Microsoft and the rest already do. From that point TikTok-sourced clicks, quiz intakes and abandons are directly countable, with no inference required. Until that exists, any claim about TikTok's contribution is unfalsifiable in either direction.

Sources: Braze REST API /events/data_series for the Abandoned Cart, Abandoned Cart - NAD+ and Abandoned Cart - Sermorelin events; Everflow Network API /v1/networks/reporting/entity for clicks by affiliate. Per-day averages exclude 2026-09-14, which is still in progress. Abandon counts are event counts rather than unique people; each person fires roughly 1.8 events on average, so the per-1,000-clicks figure is a relative trend indicator rather than an absolute per-visitor rate.
